# RoadMesh support

**What RoadMesh does.** It warns you about nearby vehicles that also run RoadMesh, using Bluetooth between phones. It is driver assistance, not a guarantee: it cannot see vehicles without the app, and it never brakes or steers.

**I see no vehicles.** Other phones nearby must run RoadMesh with a drive started, within about 100–150 m (less around buildings). Check that Bluetooth and location are on.

**Warnings stop when the screen is off (Android).** Keep the "RoadMesh is running" notification. Some phones need RoadMesh set to "Unrestricted" in battery settings.

**Language.** Settings → Language (English / ខ្មែរ), or the button at the top right.

**Mute alerts.** Settings → Alert sound, or the Mute button in CarPlay.

**Delete my data.** Settings → Delete my data.

**CarPlay.** Connect the phone and open RoadMesh on the car's screen. It shows the current warning, your speed and the nearest vehicles.

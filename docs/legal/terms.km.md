# លក្ខខណ្ឌប្រើប្រាស់ RoadMesh

*សេចក្ដីព្រាងសម្រាប់ការពិនិត្យផ្លូវច្បាប់ និងការពិនិត្យដោយអ្នកនិយាយភាសាខ្មែរ (x-needs-review)។*

1. **ជំនួយដល់អ្នកបើកបរ មិនមែនជាការធានាទេ។** RoadMesh ព្រមានអំពីយានដែលអ្នកបើកបររបស់វាក៏ប្រើ RoadMesh ដែរ។ វាមិនអាចរកឃើញយាន មនុស្ស ឬឧបសគ្គដែលគ្មានកម្មវិធីទេ ហើយការព្រមានរបស់វាអាចយឺត ខ្វះ ឬខុស។ វាមិនដែលហ្វ្រាំង បង្វិលចង្កូត ឬបញ្ជាយានឡើយ។ អ្នកនៅតែទទួលខុសត្រូវទាំងស្រុងចំពោះការបើកបរដោយសុវត្ថិភាព និងស្របច្បាប់។
2. **កុំកាន់ទូរស័ព្ទពេលបើកបរ។** រៀបចំមុនពេលបើកបរ។ ពេលកំពុងធ្វើដំណើរ គ្រាន់តែក្រឡេកមើលអេក្រង់ ហើយប្រើជើងទម្រទូរស័ព្ទ ឬ CarPlay។
3. **ការប្រើប្រាស់ត្រឹមត្រូវ។** កុំផ្ញើសារក្លែងក្លាយ កុំរំខានសារវិទ្យុរបស់អ្នកដទៃ ហើយកុំព្យាយាមកំណត់អត្តសញ្ញាណអ្នកប្រើផ្សេងទៀត។
4. **ឯកជនភាព។** សូមមើលគោលការណ៍ឯកជនភាព។
5. **គ្មានការធានា និងការកំណត់ទំនួលខុសត្រូវ។** ត្រូវបំពេញដោយមេធាវី។

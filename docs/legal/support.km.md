# ជំនួយ RoadMesh

*x-needs-review: ត្រូវពិនិត្យដោយអ្នកនិយាយភាសាខ្មែរ។*

**RoadMesh ធ្វើអ្វី។** វាព្រមានអ្នកអំពីយាននៅជិតដែលប្រើ RoadMesh ដែរ តាមប៊្លូធូសរវាងទូរស័ព្ទ។ វាជាជំនួយដល់អ្នកបើកបរ មិនមែនជាការធានាទេ៖ វាមើលមិនឃើញយានដែលគ្មានកម្មវិធី ហើយវាមិនដែលហ្វ្រាំង ឬបង្វិលចង្កូតឡើយ។

**ខ្ញុំមើលមិនឃើញយានណាមួយ។** ទូរស័ព្ទផ្សេងទៀតនៅជិតត្រូវតែប្រើ RoadMesh ហើយចាប់ផ្ដើមបើកបរ ក្នុងចម្ងាយប្រហែល ១០០–១៥០ ម៉ែត្រ។ សូមពិនិត្យថាប៊្លូធូស និងទីតាំងបានបើក។

**ការព្រមានឈប់ពេលអេក្រង់បិទ (Android)។** រក្សាការជូនដំណឹង "RoadMesh កំពុងដំណើរការ"។ ទូរស័ព្ទខ្លះត្រូវកំណត់ RoadMesh ជា "គ្មានការរឹតត្បិត" ក្នុងការកំណត់ថ្ម។

**ភាសា។** ការកំណត់ → ភាសា (English / ខ្មែរ)។

**បិទសំឡេងការព្រមាន។** ការកំណត់ → សំឡេងការព្រមាន ឬប៊ូតុងបិទសំឡេងក្នុង CarPlay។

**លុបទិន្នន័យរបស់ខ្ញុំ។** ការកំណត់ → លុបទិន្នន័យរបស់ខ្ញុំ។

**ទំនាក់ទំនង។** `<កំណត់ដោយម្ចាស់គម្រោង>`
